## 颜色候选与交付边界

颜色候选含 PF 31 / PM 32 个姓名映射及离线证据，详见
[姓名颜色说明](speaker-colors-20260906.md)。
代码和测试收录，但没有接入默认 DLL 的编译列表或初始化。
因此本 PR 不宣称玩家运行时颜色已修复，不修改生产 DLL 的批准校验值。

这份快照不是 edit_native_fields 可直接执行的写入契约。后续构建必须以目标
文件重新绑定索引/校验值，并显式支持已审换行变化；旧严格控制序列检查不能
被直接绕过。没有覆盖游戏 RIO/RUO，没有安装 DLL，没有发布玩家包。

## 可重复导出

在仓库根目录运行（输入为本地私有审计文件）：

```text
python rUGP/tools/text/export_consolidated_review.py <private-full-three-language.jsonl> --games-root rUGP/games
```

导出器只允许公开字段，保留中文控制字符；重复 binding_id、正文 U+0003、
姓名 U+2060 和不同内容的既有输出都会拒绝。manifest 包含私有输入 SHA-256、
数量及每个分片 SHA-256。此命令只导出既有决定，不自动决定任何换行。
