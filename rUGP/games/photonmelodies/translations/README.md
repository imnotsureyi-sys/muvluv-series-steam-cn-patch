# PM 中文文本编辑入口

从本目录按篇章命名的 CSV 编辑；旧资料已移到 `../text-data/`，不再人工编辑。
完整日英中对照在本地生成，操作见文末维护说明；公开 CSV 不包含完整日英原文。
当前共 **44,698 条、45 份 CSV**：

- [憧憬](憧憬.csv)：清十郎、伊尔芙莉德的故事。正文与 3 条选择文本在一起。
- [再诞](再诞.csv)：西尔维奥的故事，包括穿插的简报、旁观反应场景。
- [时空的欠片](时空的欠片/)：42 份，按原生 CRsa 场景边界拆分，不按固定条数截断。
- [共通系统](共通系统.csv)：78 条，全局菜单、章节选择与系统提示。

场景文件名是方便查找的内容标签，不是新增的官方小节名。序号依据原生存储顺序，
**不代表实机游玩顺序或分支攻略**。同一场景块的选择文本、补提取消息归入同一 CSV。
例如 `22_打西瓜教程.csv` 含 18 条正文、2 条选择文本和 36 条补提取消息，共 56 条。

正文和附属注释在同一行，审校范围保存在 `review_scope`。
完整文件、条数、原始脚本块归属见 [chapters.json](chapters.json)。
格式、历史文件用途与校验方法见[章节 CSV 维护说明](../../../docs/chapter-texts.md)。
