- 74 张剧情 telop；
- 61 张日期／地点卡；
- 42 项常用 UI 文案；
- 2 张启动提示；
- `source-image-lock.v2.json` 对 128 个英语 UI 输入及对应日语目标路径锁定 SHA-256。

`release-inventory.json` 描述历史 ZIP 真实携带的 WebP；`copy/` 描述人类可维护的中文
文案、排版和源图身份。二者作用不同，不能只保留其一。完整 WebP 二进制仍在历史
Release，重新构建时必须使用合法提取并通过来源锁。
