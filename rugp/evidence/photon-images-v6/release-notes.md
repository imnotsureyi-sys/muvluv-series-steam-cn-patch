# PF / PM 中文图片资源 1,490 张（V6）

这是 Muv-Luv photonflowers（PF）与 photonmelodies（PM）中文图片资源的审核通过备份，不是可直接安装的补丁。

## 内容

- 1,490 张中文 PNG，全部带资源 ID 与 SHA-256 清单。
- 1,247 张 PNG 与正式候选文件 SHA-256 完全一致。
- 243 张由封存游戏原生记录双解码恢复；ZIP 同时附带这些原生记录，它们仍是封包权威，禁止将解码预览 PNG 二次编码。
- 包含 `manifest.json`、包内 `SHA256SUMS.txt` 和说明文件。
