## 来源概览

- **直接移植／复用：**GARbro 的 RIO／ICI 目录读取逻辑；Noto 字形、官方图片等内容复用另列，不与代码贡献混算。
- **参考后实现与适配：**Cr6Ti 参考 AFHook／AFEditor／alterdec；CRip007 参考 GARbro 并补充 AGES7 适配；CRmti 参考 alterdec／rugptools 的预测基础，以及 muzhi 的 **RioX 1.2.143.810** 反汇编。Hook 的技术先例也注明 AFHook。
- **本项目研究并完成：**CRip008 解码及 kind2／kind3 编码、两作专用原生文本解析和中文写回、CRmt 父结构与资源绑定、版本专用运行时、字体与界面适配、中文素材处理、安装集成及具体故障修复。格式本身属于官方，不宣称发明格式或全球首创。

## 最终路线

直接修改／扩展 RIO → 尝试正文与图片集中到单份 RUO1 → 按对象及显示路径分流 → **RIO／ICI＋每作一份 RUO1＋专用 DLL／PNG／字体**。

最终两作正文均写入 RIO；RUO 保留指定图像对象，普通图片主要经 DLL 加载 PNG。历史追加数据仍有保留，不能把阶段性“PF 文本走 RUO”或“所有 RIO 都等长修改”当作最终包结构。
