## 状态与边界

- 参考术语经过类别筛选，保留原译实际用法；不是所有出现位置都经过逐条语义审定。
- `reference_observed_not_global_replacement` 表示参考原译，不允许全局替换；`observed_speaker_label` 只适用于完整说话人标签。
- 公共参考不覆盖各作决定，不继承 TDA、帝都燃烧、PF、PM 的专表，不修改这些作品的正文、换行或字体。
- 本地规则词串索引为本篇 11,820 项、AL 14,882 项，含普通词、代词、拟声词和切分片段。它们没有全部人工审定，也不等于作品的专有术语总量，不能宣称“全部术语审核完成”。
- 本地称谓索引保留三语上下文，不推定 `さん＝同学` 等全局对应。

## 值得注意的原译差异

- AL 的 `光線級／重光線級` 原译为“激光级／重激光级”。这里保留其证据，但项目已确认的“光线级／重光线级”不变。
- `ヴァルキリーズ` 有“女武神／女武神中队”及 `Valkyries` 等写法；带编号的 `ヴァルキリー` 还用于呼号，不直接替换成中队全称。
- `エコー／ウィスキー` 在 AL 登陆作战语境有 `Echo部队／Whiskey部队`。需区分原文“部隊／艦隊”，不把所有场合套成舰队，也不据此自动重写其他作品。

## 提取与校验

本篇中文包的英文语言索引为空，英文取自日英更新包。按日文脚本序列对齐后，全部 60,393 条日文字段与日英包对应字段逐字完全相同。AL 按原生三语言索引读取。

扫描覆盖所选资源的全部 767 个 CRsa 记录，并回读校验 404,557 个非空索引语言字段。日英本篇及 AL 更新包覆盖各自基础包的全部 CRsa；不重复计数基础包与更新包。4 个初始解析异常为无译文索引的控制记录，未计入正文。所有公开词条的出处在本地基线中存在。

[统计](summary.json)区分正文、系统三语记录、规则候选和参考词对；[来源校验](source-verification.json)仅保留资源文件名、大小和校验计数。部分脚本块无原生标题，本地索引保留块 ID，不编造章节名称。解析范围是 CRsa 内消息及序列化字符串，不代表穷尽所有图像、音频或其他对象中的术语。

每个公开词条的 `evidence` 只保留至多两个来源 ID、记录哈希和三语言字段哈希；`occurrences` 是本地全部命中数，不是公开证据样本数。哈希提供本机复核依据，不能单凭哈希证明语义正确。命中统计包含上下文中的子串，因此仍须遵守词条适用说明。

## 公开导出

实验性完整提取脚本及完整来源数据目前仍在本地，本 PR 不将其包装成通用提取器。这里提供的工具仅负责从已校验的本地结果导出公开安全的参考快照：

```powershell
python -m localization.tools.export_main_al_reference --local-results <本地结果目录> --output <新的输出目录>
python -m unittest localization.tests.test_main_al_reference -v
```

导出采用字段白名单，排除完整例句、正文及本机路径，并拒绝覆盖既有导出文件。没有修改发布约定或启用新的生效术语字典。
