# 本篇／AL 独立术语发现（非生效参考）

本轮先从本篇和AL的源记录独立发现、筛选，冻结后才与七作现行表交叉核对；没有使用旧101／193项名单作为种子。旧快照仍保留在相邻目录，不与本目录相加计数。

|项目|本篇|AL|
|---|---:|---:|
|扫描源记录|60,393|54,329|
|独立日文词形|403|529|
|中文变体|406|551|
|说话人标签对|167|296|
|所选证据去重源记录|356|471|

- `ml-independent-baseline.json`、`al-independent-baseline.json`：词形、中文变体、分类、来源ID和日英中字段哈希。
- `ml-speaker-baseline.json`、`al-speaker-baseline.json`：完整标签对应及来源哈希，多人组合不能计为人物数量。
- `shared-forms.json`：77个两作共同归一化词形；共同出现不意味着可直接进入通用表。
- `discovery-freeze.json`：独立发现结束时的本地输入哈希、时间与计数。公开去例句版本的文件哈希当然不同于该本地冻结哈希。

932个按作计数的词形包含专名、技术词、称谓和局部文化表达，均标记不得自动替换。它们不是932条全局强制术语。完整114,722条扫描不等于逐句人工通读；46,282个机器候选不是全部人工审定项目。

完整官方日英中例句、机器候选和审核页留在本地。公开导出使用字段白名单，仅保留术语级标签与来源哈希。系列当前采用的光线级、女武神等规则不因参考中有其他译法而自动撤回。原译异体、疑点也不能直接当成推荐译法。

复现：`python localization/tools/export_independent_main_al.py --source <本地独立提取目录> --destination <不存在的新输出目录>`。
