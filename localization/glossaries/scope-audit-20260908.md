# 术语来源、污染与分作整理审计

> 本报告的“来源齐全／整理完成”结论已撤回。首次审计漏查旧 `patch-sources` 中的 PF/PM 独立术语表和完整基线，也漏查了 2,194 行 TSV。以下数量仅是当时四份输入的历史快照，不代表当前生效表、各作原始术语总量或完整审计结果。当前整理见 [恢复说明](recovery-20260908.md) 和 [入口](README.md)。

## 查明的来源

这不是一张经过共通性审核的系列总表，也不只是单独一张 TDA 术语表。

1. 公开历史的初始 871 条，与本机旧 ParaTranz 五列表的前两列逐条、顺序完全一致。
2. 本机 Luna 旧词库共 1,120 条，保留过 TDA、TDA角色、TDA呼号、Photon角色、Total Eclipse、Schwarzesmarken 等类别。不能把这些类别视为七作共同适用。
3. #8 又向同一表追加 21 条 Photon 审核词条，上一轮增加了 2 个激光级别名，整理前共 894 条。
4. 帝都燃烧已有独立表 185 条，但其中“ァァ”等普通词/片段带“主库术语表”来源，证明确有向下传播。
5. TDA00 的本地候选草案另有 369 条；它不是已确认的通用术语表。

[逐条记录](scope-audit-20260908.json)收录四份输入的 2,568 个源记录（不同来源有重复，不是 2,568 个独立术语）。每条均保留原词、原译、来源行号、归属与状态。旧 ParaTranz 871 条与混合表前缀完全一致，因此不另重复计数。

## 确认的问题及处置

| 旧映射/现象 | 问题 | 处置 |
| --- | --- | --- |
| ァァ → 啊啊 | 惊呼/拉长音片段，不能规定每次都补“啊啊” | 所有生效表退出；不删除正文里合理的“啊啊” |
| ウチ → 我方/本舰 | 人称依语境变化，斜杠也不是唯一译文 | 退出强制术语 |
| 女衛士 → 女卫士1 | 旧 Luna 原条为女卫士，无依据多了编号 | 不保留此映射；有编号的完整说话人另行核对 |
| 多分隊長 → 大概是队长 | 句子片段被当作术语 | 退出 |
| 軌道降下兵 → 轨道潜水员 | 旧 Luna 为轨道降下兵，TDA/PF 正文亦支持后者 | 恢复相关本作表的轨道降下兵，原错误进入记录 |
| ウィル命中ウィルス | 人名与“病毒”的片假名子串碰撞 | 按作品加载，片假名边界匹配；候选仍需看语境 |
| 響命中影響 | 单字名称错误命中普通词 | 名称限定本作/完整说话人字段，不做正文替换 |
| PF/PM 皮亚蒂芙等现行名称与旧表不同 | 泛用旧音译不应覆盖本作已采用名字与颜色识别 | 在本作表记录已核对名称，不修改正文或运行时颜色别名 |

普通动词、泛称、计量词、拟声片段及有明显附加含义的条目退出生效表。专名/呼号必须有本作证据；仅在旧百科扩展或未经复核草案中出现的条目保留待确认，不自动塞回通用表。

通用表是人工选定的 139 条共通专名/军事术语；不是“任意两作出现即通用”。旧“量子電導脳 → 量子导电脑”缺少本次可验证的语境支持，也退出通用表，保留待确认。
七作专表之间不继承。生效范围见[总入口](README.md)。

## 单独发现的源槽关联疑点

`pm:vm:photonmelodies11.rio.004:655753292:00031180:00157`：本机三语源记录日文是武在说天气好，英文是 Kasumi 在说情况不妙；现行中文对应霞和英文内容。不能只把“霞”改成“武”，须先核对原始槽位关联。

PM 的日文【武】在现行中文有 10,798 次对应【武】、1 次对应【霞】。前者用于本作完整说话人字段，“武 → 霞”不进入任何术语表。该疑点未在本轮自动修复，不影响其他正常姓名映射的保留。
