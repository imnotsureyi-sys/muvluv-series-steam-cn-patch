# 共通术语表说明

当前简体中文术语表是 [`muv-luv.ja-zh-Hans.csv`](muv-luv.ja-zh-Hans.csv)。它沿用项目现有的 `jp,cn` 两列格式，服务于日文到简体中文的翻译与校对；`cn` 是历史字段名，不表示所有目标语言都应使用中文列。

新语言应新建独立文件，例如 `muv-luv.ja-ko.csv` 或 `muv-luv.ja-ru.csv`，并在该语言的规范中说明目标列名、标点和专名规则。不要覆盖 `muv-luv.ja-zh-Hans.csv`，也不要把英文槽当成日文原文的替代来源。

旧 LunaTranslator 表、ParaTranz 辅助导入表、来源笔记和一次性中间表属于本地工作资料，不是公开术语表的权威来源。

## 维护流程

发现新术语时：

1. 在对应游戏或章节的候选记录中保存日文、上下文、候选译法和依据。
2. 由译者或审校者提交变更；影响多个游戏的词条需说明影响范围。
3. 维护者审核后合并到目标语言的正式术语表。
4. 相关游戏重新运行术语一致性检查；正文变更通过各自的翻译表提交，不在术语表中直接改写章节文本。

## 判断优先级

1. 已合并且适用于当前语境的目标语言术语。
2. 作品内日文语境和官方日文设定。
3. 有可靠出处且经项目审核采用的目标语言惯用译名。
4. 根据专名类别作出的音译、意译或保留拉丁字母决定。

存在歧义时保留为候选或 `question`，并记录依据；不要静默猜测。完整流程见 [`../standards/terminology.md`](../standards/terminology.md)。
