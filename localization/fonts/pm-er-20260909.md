# PM“珥”字增补候选

仅用于本轮日珥计划文本。字体二进制保留在本地隔离候选，不提交Git；不得单独替换游戏字体。完整输入/输出哈希见[审计](../../rUGP/evidence/photon/text/pm-font-er-20260909.json)。

## 复现

使用Python 3.12及fontTools 4.63.0。从仓库根目录执行；`X:\candidate`必须是新的候选目录。PM旧字体和Noto Sans SC输入必须逐字节匹配审计哈希，否则工具拒绝。

```powershell
python -m localization.tools.repair_pm_vertical_metrics --input "X:\old\PhotonR2-Regular.ttf" --output "X:\candidate\repaired-base.ttf"
python -m localization.tools.extend_font_subset --base "X:\candidate\repaired-base.ttf" --base-sha256 16D36CD744E146B8303AECB65DCBFE01FCA58AE701B46226411BBB8F7F99AB6E --donor "X:\source\NotoSansSC-VF.ttf" --donor-sha256 763146584CF0710223441356B4395E279021B0806C196614377A7A0174AE074A --characters 珥 --weight 400 --output "X:\candidate\PhotonR2-Regular.ttf"
python rUGP/runtime/build.py --game pm --zig "X:\zig\zig.exe" --output "X:\candidate\pm\Ages3ResT.dll" --authorize-pinned-build --speaker-color-candidate --pm-font-candidate
```

两次隔离编译的一致性由运行时构建器验证。该候选不更新默认正式配置，也不支持`--verify-release-code`。

## 修复边界

- 旧字体新增227个PUA字形时没有同步增加vmtx项。修复仅接受这个已审核字体，不对任意坏字体进行猜测性修补。
- 对缺失项明确采用进给1000、竖排原点880的规则，与原字体主要CJK度量惯例一致；不称之为历史原始度量。
- 原有4715项竖排度量字节保留；其余表除vhea/vmtx和head校验值之外字节不变。
- 再追加U+73E5；旧4942字形与横向度量、字符身份、修复后的竖排度量和排版表保持不变。
- 全部菜单PUA在三种字号下像素对比一致；24px的GDI行宽诊断通过。不据此宣称实机已验收。

## 来源与许可证

本机锁定的Noto Sans SC变体源于[Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)；上游当前文件可能更新，不能用同名新版跳过哈希校验。基底PhotonR2也带有Adobe版权和OFL-1.1声明，家族名已改为PhotonR2。

正式分发字体时附上[完整OFL与版权声明](NotoSansSC-OFL.txt)，并保留修改来源说明。该步骤不会自动解决其他补丁资产的发布授权问题。

仍需按既有打包合同组装匹配的正文、字体和运行时，再由维护者实机抽查后发布。
